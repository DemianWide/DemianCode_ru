# Инструкция: запуск, сборка и публикация

Сайт на чистом HTML, CSS и JavaScript. Установка программ и `npm install` не нужны, понадобится только Python (он у вас уже есть, раз работает `start.bat`).

## 1. Где что лежит

Всё в одной папке `C:\Users\Demian\Portfolio_Frontend\`:

```
Portfolio_Frontend/
├── index.html            главная: первый экран, работы, обо мне, контакты
├── project.html          страница кейса (?p=storecrm и т.д.)
├── css/
│   ├── portfolio.css     основной дизайн и темы
│   └── fx.css            эффекты: аврора, курсор, шторка, частицы
├── js/
│   ├── portfolio.js      отрисовка страниц из data/site.js
│   └── fx.js             анимации
├── data/site.js          ВСЕ тексты, список работ, контакты
├── assets/img/           своё фото и скриншоты работ
├── сайт_1/               StoreCRM (дашборд и канбан)
├── сайт_2/               FinDash (финансовый дашборд)
├── сайт_3/               FIELDCODE (визитка с 3D и заявками в Telegram)
│   └── server/           send.php для заявок (лежит отдельно, на хостинг попадает при сборке)
├── docs/                 эта инструкция и текст для резюме
├── tools/build_dist.py   сборка для хостинга
├── start.bat             запуск на своём компьютере
├── build.bat             сборка папки dist
└── _backup_originals/    ваши исходные файлы до моих правок
```

## 2. Запуск у себя

1. Двойной клик по **`start.bat`**. Откроется `http://localhost:8090`.
2. Окно с чёрным фоном не закрывайте, пока смотрите сайт. Закрыли окно, и сервер остановился.
3. Если порт занят, откройте `start.bat` блокнотом и поменяйте `8090` на другое число (в двух местах).

Двойной клик по `index.html` тоже работает, но 3D-модель в FIELDCODE и заявки там не заработают: браузер не даёт читать файлы напрямую.

## 3. Как менять содержимое

| Что поменять | Где |
|---|---|
| Тексты, контакты, соцсети, список работ | `data/site.js` |
| Своё фото | положить `assets/img/me.jpg` (4:5) |
| Скриншоты работ | положить `assets/img/work-fieldcode.webp`, `work-storecrm.webp`, `work-findash.webp` (16:10) |
| Картинки StoreCRM | `сайт_1/img/` (имена в `сайт_1/img/README.txt`) |
| Цвета и тема | переменные в начале `css/portfolio.css` |
| Тексты визитки | `сайт_3/config.json` |

После правки `config.json` визитки запустите `build.bat`: он обновит `config.js` (копия для открытия без сервера).

**Добавить новую работу:** положите страницу в папку (например `сайт_4/index.html`), скопируйте любой блок в `projects` в `data/site.js`, поменяйте `slug`, названия и путь в `demos`. Карточка на главной и страница кейса появятся сами.

Если после правок браузер показывает старое, нажмите **Ctrl+F5**.

## 4. Сборка для хостинга

1. Двойной клик по **`build.bat`** (или в консоли: `python tools\build_dist.py`).
2. Появится папка **`dist/`**. В ней:
   - папки переименованы в латиницу (`site-1`, `site-2`, `site-3`), потому что кириллица в путях на хостингах часто ломает ссылки;
   - пути в `data/site.js` уже исправлены;
   - рядом с `site-3/index.html` лежат `send.php` и `send.config.example.php` для заявок;
   - служебное (бэкапы, `docs`, `tools`, старый `portfolio.html`) не попало.
3. Скрипт пишет список напоминаний: чего не хватает (фото, скриншоты, заглушки в контактах). Если он пишет **ОШИБКИ**, демо-страница не найдена, исправьте путь в `data/site.js`.

`dist/` можно удалять и собирать заново сколько угодно раз. Исходники он не меняет.

## 5. Публикация

Загружайте **содержимое** `dist/` (не саму папку) в корень сайта на хостинге.

**Куда:** при вашем VPN-вопросе лучше российские хостинги: Timeweb, Beget, Selectel, Reg.ru или Yandex Cloud. Для статического сайта подойдёт любой самый дешёвый тариф. Запасной вариант: GitHub Pages (бесплатно, но иногда медленно открывается из России).

**Как загрузить:** через файловый менеджер в панели хостинга или по FTP (программа FileZilla). Главное, чтобы `index.html` оказался в корне (`public_html` или `www`).

**Адрес и HTTPS:** в панели хостинга привяжите домен и включите бесплатный сертификат (Let's Encrypt). Без HTTPS не работают некоторые функции браузера, например копирование email кнопкой.

После публикации откройте сайт с телефона и проверьте: темы, меню, вкладки в кейсе, 3D в FIELDCODE.

## 6. Заявки в Telegram (форма в визитке FIELDCODE)

Работает только на хостинге с PHP 8+ (не при запуске у себя).

1. В Telegram откройте **@BotFather** → `/newbot` → получите **токен**.
2. Напишите созданному боту любое сообщение, затем откройте в браузере `https://api.telegram.org/bot<ТОКЕН>/getUpdates` и найдите `"chat":{"id":ЧИСЛО` — это **chat_id**.
3. На хостинге в папке `site-3` скопируйте `send.config.example.php` в **`send.config.php`** и впишите токен, chat_id и адрес сайта в `origins`.
4. Проверьте: нажмите на сайте «Выбрать «Старт»», заполните форму. Сообщение должно прийти в Telegram.

Некоторые российские хостинги не достают до `api.telegram.org`. Если заявка не приходит, напишите в поддержку хостинга или задайте прокси в `send.config.php`. Подробнее: `сайт_3/server/README.md`.

**Файл `send.config.php` никому не отправляйте и не выкладывайте в GitHub:** он в `.gitignore`.

У самого портфолио формы нет: кнопка «Написать» ведёт к блоку контактов с вашей почтой и соцсетями из `data/site.js`, серверная часть ему не нужна.

## 7. Если что-то не работает

| Что видите | Что делать |
|---|---|
| Белый экран или «не загружен data/site.js» | Откройте консоль браузера (F12), ищите красную ошибку. Чаще всего опечатка в `data/site.js` (лишняя запятая, кавычка) |
| 3D-модель не открывается | Запустите через `start.bat` или откройте на хостинге, а не двойным кликом |
| В превью работ пусто | Подождите секунду, превью грузит страницу целиком. Или положите свой скриншот `work-*.webp` |
| Графики в дашбордах пустые | Нужен интернет: Chart.js подгружается с CDN |
| Курсор-кольцо мешает | Откройте `js/fx.js` и закомментируйте строку `safe(cursor);` в конце файла |
| Лишние анимации | Отключаются по одной строкой `safe(...)` в конце `js/fx.js` |
| Старая версия после правки | Ctrl+F5 |
| Заявка не приходит в Telegram | Раздел 6, пункт про доступ хостинга к Telegram |

## 8. Резервная копия

Всё нужное лежит в одной папке, поэтому достаточно периодически копировать `Portfolio_Frontend` (без `dist/`) на флешку или в облако. Для работы с историей версий можно завести репозиторий на GitHub: `.gitignore` уже настроен и не пропустит секреты.
