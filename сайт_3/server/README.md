# Заявки с сайта в Telegram

Кнопки цен и связи открывают окно заявки. Оно отправляет данные на `send.php`, а тот пересылает их вам в Telegram.
Токен бота хранится только на сервере, в браузер он не попадает.

## Настройка (один раз, ~5 минут)

1. **Создать бота.** В Telegram откройте @BotFather → `/newbot` → задайте имя → получите **токен**.
2. **Узнать свой chat_id.** Напишите вашему новому боту любое сообщение (иначе он не сможет писать вам первым).
   Затем откройте в браузере `https://api.telegram.org/bot<ТОКЕН>/getUpdates` и найдите `"chat":{"id":ЧИСЛО`. Это и есть chat_id.
3. **Положить файлы на хостинг** (нужен PHP 8+, подходит любой обычный хостинг):
   - `server/send.php` → в корень сайта, рядом с `index.html`;
   - `server/send.config.example.php` → скопировать как `send.config.php` туда же и вписать токен, chat_id и адрес вашего сайта в `origins`.
4. Проверьте: откройте сайт, нажмите «Выбрать «Старт»», заполните и отправьте. Сообщение должно прийти в Telegram.

Адрес скрипта задаётся в `config.json` → `lead.endpoint` (по умолчанию `send.php`).

## Важно

- **Доступ хостинга к Telegram.** Некоторые российские хостинги не достают до `api.telegram.org`. Если заявка не приходит, а форма показывает ошибку,
  напишите в поддержку хостинга или задайте прокси в `send.config.php` (`'proxy'`). Запасной вариант: небольшой Worker/функция на другой платформе, которая принимает тот же JSON.
- **Пока нет серверной части**, форма не ломается: после ошибки она показывает ссылку «Написать в Telegram», чтобы заявка не потерялась.
- **Спам.** Уже есть скрытое поле-ловушка, лимит 5 заявок за 10 минут с одного IP и проверка адреса сайта.
- **Файл `send.config.php` никому не отправляйте** и не выкладывайте в GitHub.
