# Портфолио Дмитрия

Сайт-портфолио на чистом HTML, CSS и JavaScript. Без сборки и зависимостей.

## Как запустить

- **Быстро:** двойной клик по `index.html`. Всё работает, кроме 3D-модели в работе FIELDCODE (браузер не даёт читать файлы модели напрямую).
- **Полностью:** запустите `start.bat`. Он откроет сайт на `http://localhost:8090`, там работает всё, включая 3D.

## Что где лежит

| Файл или папка | Что это |
|---|---|
| `index.html` | Главная: первый экран, работы, обо мне, контакты |
| `project.html` | Страница кейса (открывается как `project.html?p=storecrm`) |
| `data/site.js` | **Все тексты, список работ и контакты.** Правится только он |
| `css/portfolio.css` | Стили, тёмная и светлая темы |
| `js/portfolio.js` | Скрипт |
| `сайт_1/` | StoreCRM: дашборд и доска заказов |
| `сайт_2/` | FinDash: финансовый дашборд |
| `сайт_3/` | FIELDCODE: сайт-визитка (копия готовой версии) |
| `_backup_originals/` | Ваши исходные файлы до моих правок |
| `docs/BUILD.md` | Инструкция: запуск, сборка, публикация, заявки в Telegram |
| `docs/RESUME.md` | Тексты для резюме и продажи услуг |
| `tools/build_dist.py`, `build.bat` | Сборка папки `dist/` для хостинга |
| `css/fx.css`, `js/fx.js` | Эффекты и анимации |
| `portfolio.html` | Старый файл портфолио, я его не трогал |

## Что заменить своим

1. **Контакты.** В `data/site.js`, блок `contact`: email, Telegram, GitHub, Behance. Сейчас там заглушки.
2. **Своё фото.** Положите `assets/img/me.jpg` (портрет, пропорции 4:5). Пока файла нет, показывается буква «Д».
3. **Скриншоты работ.** Положите в `assets/img/` файлы `work-fieldcode.webp`, `work-storecrm.webp`, `work-findash.webp` (пропорции 16:10, например 1600×1000). Пока их нет, в карточках показывается живое уменьшенное превью самой страницы. Появился файл — сайт возьмёт его сам.
4. **Картинки для StoreCRM.** В `сайт_1/img/` (список файлов в `сайт_1/img/README.txt`). Пока их нет, подставляются фото с Unsplash.
5. **Тексты кейсов.** В `data/site.js`, блок `projects`: описание, задача, что сделано, стек.

## Как добавить новую работу

1. Положите страницу в папку, например `сайт_4/index.html`.
2. Скопируйте любой блок в `projects` в `data/site.js`: укажите `slug`, название, описание и в `demos` путь к странице.
3. Всё: карточка на главной и страница кейса появятся сами.

## Публикация

- Для хостинга лучше переименовать папки `сайт_1`, `сайт_2`, `сайт_3` в латиницу (`site-1` и так далее) и поправить пути в `demos` в `data/site.js`.
- На страницах работ есть кнопка «← К портфолио», она ведёт на `../index.html`, поэтому структуру папок меняйте вместе с этой ссылкой.
- Дашборды берут Chart.js с CDN: нужен интернет.
